## What xummary does

xummary reads your X timeline for you. It fetches your For You and Following feeds, sends them to Claude, and gives you one briefing of what happened, grouped by story. You read one page and close it, instead of scrolling.

This first release has:

- a Mac app that shows the briefing, and refreshes it when you pull down or press ⌘R
- a `xummary` command that prints the same briefing in a terminal
- one briefing that stays up to date: a refresh downloads only the new posts and rewrites only the stories that moved
- a mark on each story that is new or has changed since you last read the briefing
- links from each @handle to the post it is about, and a list of sources under each story
- a briefing in French by default, or in another language with `--lang`

xummary uses the x.com session already in your browser, so it needs no X password and no API key. It uses your `claude` login to write the briefing, with Sonnet 5.5 by default. A refresh takes about 40 seconds.
